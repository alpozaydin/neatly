# neatly vs Finder, Shortcuts and Hazel

There are several ways to rename files on a Mac. They solve different problems, and many people use more than one.

| | Reads the file? | Automatic? | Bulk? | Price |
|---|---|---|---|---|
| **Finder: Rename items** | No | No | Yes | Built in |
| **Finder: suggested names** (Apple Intelligence) | Yes | No | No, one file at a time | Built in |
| **Shortcuts + Apple Intelligence** | Yes | With a folder action | You build it | Built in |
| **Hazel** | Partly, with rules you write | Yes | Yes | Paid |
| **neatly** | Yes | Yes | Yes | Free, open source |

## Finder: Rename items

Select files, right-click → **Rename**. You can replace text, add text, or use a format like `Holiday 1, Holiday 2`.

**Best for:** renaming a batch with a pattern you already know. It doesn't read the files, so it can't give each one a
meaningful name.

## Finder: suggested names

With Apple Intelligence on recent macOS, Finder can suggest a name when you rename a document.

**Best for:** naming one file you're already looking at. It works one file at a time and only when you ask, so it
doesn't help with a full Downloads folder or every new screenshot.

## Shortcuts with Apple Intelligence

You can build a Shortcut that reads a file's text, asks Apple Intelligence for a title and renames the file, then
attach it to a folder.

**Best for:** people who enjoy building automations. You handle duplicates, files without text, folders and Undo
yourself.

## Hazel

Hazel watches folders and runs rules you write: "if the name contains *invoice*, move to Bills".

**Best for:** predictable, repeated filing based on names, dates, types and text. You write a rule for each case.

## neatly

[neatly](../) reads each file (page 1 of a PDF, the text on a screenshot, what a photo shows) and names it by what it
is, automatically, on your Mac.

**Best for:** new downloads, screenshots and photos with junk names, and cleaning up a messy folder once. It suggests
folders too, and "Always do this" turns a choice into a rule. It never renames files you named yourself, and every
change can be undone.

**Use them together.** neatly gives files real names; Hazel rules or Finder patterns can then file them by those names.
